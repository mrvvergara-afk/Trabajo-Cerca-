# Identidad Stitch

SVG horizontal y compacto decodificados de code.html del ZIP proporcionado por el propietario. El radar es el mismo grupo gráfico del logo horizontal, con viewBox de 120×120. Sin scripts ni recursos externos. No se modifican iconos de instalación PWA en esta entrega.

La propuesta contiene datos de demostración, mensajes en vivo y una paleta azul/cian; la implementación usa la paleta verde solicitada, conteos reales y filtros existentes, sin distancias o actividad no acreditadas.
