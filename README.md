# Trabajo Cerca — Radar externo experimental

Motor independiente para recolectar fuentes públicas locales y detectar candidatos a empleo en comunas objetivo.

- No modifica el inventario de AppDeploy.
- No requiere credenciales para su primera prueba.
- No publica avisos automáticamente: genera artefactos auditables.
- No usa scraping de áreas privadas ni evita controles de acceso.

La ejecución manual se inicia desde Actions > Radar local > Run workflow. Los resultados se descargan en Artifacts (JSON).
